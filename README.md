# Devfolio – Prasaath Kondreddy

A responsive single-page portfolio built with semantic HTML, Flexbox and CSS Grid. It has an About section, a Projects grid, and contact links, with no frameworks or build step.

**Live URL:** https://YOUR-GITHUB-USERNAME.github.io/devfolio/

## Run locally

1. Clone the repo: `git clone https://github.com/YOUR-GITHUB-USERNAME/devfolio.git`
2. Open `index.html` in a browser (or run `python3 -m http.server` and visit `http://localhost:8000`).

## Deploy on GitHub Pages

1. Push the project to a public repo named `devfolio` with `index.html` at the root.
2. Go to Settings → Pages → Source: Deploy from a branch → `main` and `/ (root)` → Save.
3. After about a minute, open the live URL above.

## Files

- `index.html` – page structure and content
- `style.css` – colour and type variables, layout, and the responsive breakpoints
